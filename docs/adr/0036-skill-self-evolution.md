# 技能自进化：lingshu-plugin-dev 每次插件闭环强制进化（阶段 5）

现状：根 `AGENTS.md` 第 3 条「规则实时升级」要求遇到新问题立即同步文档，但属**软约束**——记得就写，不记得就漏；且只说了「写哪里」，没说「什么算一次」「什么才配记」「怎么写才不灌水」。`lingshu-plugin-dev/SKILL.md` 已 719 行，踩坑节 20+ 条无索引，再无节制追加 = 自膨胀。

## 决策（2026-09 grill-with-docs 两轮确认）

1. **触发 = dev 闭环 + commit 幂等检查**：「一次」= 一次有结论的开发闭环（调通 / 放弃 / 提交），不是文件保存、不是单次 simulator run。commit 触及 `lingshu-plugins/<id>/*` 时再做一次幂等检查（防漏）。typo / 版本号 bump / 纯格式化免检。
2. **主体 = 开发 agent 自省为主**：同会话收尾花 5 分钟做 reflection-distill。只有触及新契约 / 新 ADR 级别时才起独立 reviewer 二次提炼。git hook 只做 warn 兜底（本次不做脚本，等跑 3–5 个插件真漏了再补）。
3. **内容三级**：L1 踩坑追加 / L2 模式提炼（合并同类坑）默认允许；L3 结构重构（删过时、拆 references）需显式批准。默认只跑 L1+L2。
4. **落点复用现有链**：`docs/agents/plugin-host-boundary.md` 判定插件侧 / 宿主侧 + `0034` 分层（主文件一行红线、全文进主题文档）。不发明第二套落点。跨侧问题两侧分别记录并互引。
5. **防膨胀双门**：每次必跑去重（`codegraph explore "<新坑关键词>"` 查 SKILL + references + 相关 docs，新条目必须列出查过哪几个旧条目）；SKILL 主文件行数熔断（超限逼做 L2 合并 / 申请 L3 压缩，不再追加）。
6. **强制 = 阶段 5 DoD**：SKILL 阶段 4 后加「阶段 5：技能自进化」，输出 5 段式进化报告（本次改动一句话 / 通用度判定 / 落点 / 去重结果 / 无则写「无通用经验」+ 理由）。允许「无进化」——换站不复现、只与本站 DOM/接口字面量有关即无；强制每次写出东西 = 强制灌水。
7. **术语**：`CONTEXT.md` 新增「技能自进化 / 进化报告」两词条（一句话 + `_Avoid_` + 详见本 ADR），行为细则只在本 ADR 与 SKILL 阶段 5，不进词条。
8. **模板同步更新**：自进化结论触及通用契约/骨架（新增插件方法、返回结构变化、通用 helper、沙箱红线约束）时，必须同步更新 `lingshu-skills/lingshu-plugin-dev/template.plugin.js`，使模板与 SKILL + `references/*` 保持一致（本次模板补齐即因长期只改文档、模板滞后而起）；只与本站 DOM/接口字面量有关的个例不碰模板。更新后跑 `node --check` 校验语法，进化报告的「落点」段注明模板是否同步及其理由。

## 非目标

- 不做 git hook 机械门禁（误报高）；不做全量记录（每次改啥都记）；不做 SKILL 大拆（本次只加索引 + 修跳号，大重构待 L3 批准）。

## 验证

- 下一个插件 dev 闭环必须在回复末尾带 5 段式报告；连续 3 个插件验证去重行之有效、SKILL 行数不失控。
